### Frameworks

#### [Pytorch](https://pytorch.org/get-started/locally/)
* Linux
    ```bash
    pip3 install torch torchvision --index-url https://download.pytorch.org/whl/cu132
    ```
* Windows
    ```powershell
    pip3 install torch torchvision --index-url https://download.pytorch.org/whl/cu132
    ```
Test
```shell
python -c "import torch; print(torch.__version__)"
```
